# Links

Личная страница-визитка с плашками-ссылками (linktree-стиль).
Хостится на GitHub Pages: **https://klambotsky.online/links/**

Корень домена (`https://klambotsky.online/`) перенаправляет на `/links/`.
Полное портфолио пока живёт по скрытому адресу `/h4vx9qm2nr/`.

---

## Что здесь есть

- Профиль (аватар, имя, описание), иконки соцсетей, карточки-ссылки
- Кнопка «Смотреть портфолио» → `/h4vx9qm2nr/` (когда портфолио переедет на `/`, достаточно сменить `href`)
- Футер: «since 1986», ротация «Люблю [что-то]», по клику на «since 1986» — счётчик дней с 7 декабря 1986
- Светлый холст, шрифты и акцент в одном стиле с полным сайтом

## Как править

### Добавить или изменить ссылку-плашку

В `links/index.html` в блоке `<nav class="links">` скопируй один из `<a class="link-card ...">` и поменяй `href`, текст `link-card__label` и при желании `link-card__desc`. Не забудь добавить класс `anim-item` и свой `style="--delay: N"` (N — следующий по счёту, чтобы анимация шла по порядку).

Кнопка портфолио — `<a class="cta" href="/h4vx9qm2nr/">`. Чтобы направить её на корень домена, поменяй только `href`.

### Список «Люблю»

В `links/script.js` массив `ROTATING_TEXTS` — это то, что подставляется после слова «Люблю». Меняй строки, добавляй или убирай.

### Цвет акцента и токены

В `links/style.css` в `:root` те же роли, что у портфолио: `--ink`, `--surface`, `--accent` (`#e6ff2b`).

### Аватар, OG-картинка, favicon

- Аватар: замени файл `links/avatar.png` (рекомендуемый размер 176×176 или 96×96).
- Превью при шаринге: замени `links/og.png` (рекомендуемый размер 1200×630).
- Иконка во вкладке: замени `links/favicon.png` и корневой `favicon.png`.
